# 电吉他乐理（本地网站）

和 `agent-roadmap` 同一套方法：找权威资料 → /teach 生成 HTML 讲义 → 抱着琴走一遍讲义 → 有重点地看原资料并上琴验证 → AI 反问。区别是每个知识点都要过三关：弹得出、听得出、说得出。

双击 `index.html` 就能用，不需要联网或装任何东西（资料链接本身需要联网）。进度保存在浏览器的 localStorage 里，换浏览器前在「设置」里导出备份。

也可以起一个本地服务再打开：

```bash
python -m http.server 8766 --directory guitar-theory
```

然后访问 http://localhost:8766 。

## 路线

5 个阶段、15 个模块，标准节奏（每天约 75 分钟，周末也练）共 65 个练习日：

1. 指板与听觉地基：音名与指板、节奏与读谱、音程
2. 音阶与和弦的构造：大调与五度圈、三和弦与 CAGED、七和弦与和弦符号
3. 调性和声：顺阶和弦与罗马数字、功能与常见进行、小调体系
4. 电吉他的语言：五声 5 个把位、布鲁斯、调式
5. 进阶与综合：和弦音即兴、调外和弦与转调、扒歌与曲式

主资料是 Open Music Theory（大学开放乐理教材）和 JustinGuitar（吉他教学者的系统课程），辅以 musictheory.net 练习、MIT OCW 21M.051 和几本公认的吉他乐理书。

## 页面

- **今天**：当天的模块、学习循环进度环（点节点勾选）、要勾掉的任务、今日节奏、日练、今天的曲目、落后提醒
- **本周**：从开始日期算起每 7 天一周，每天一张卡片和进度条。点开就是那一天的全部内容：时间表、讲义入口、要精读的原文（嵌在页面里，中文 / 中英对照 / English 可切换）、合上资料回答的问题、上琴练习和完成标准、验收、自测、曲目、日练、/quiz 命令
- **方法论**：五步学习循环、三层递进、原则、全部提示词模板
- **路线图**：甘特图 + 15 个模块的学习包（重点、资料、上琴练习、产出、验收、反问种子、一键复制提示词）
- **能力自评**、**自测题库**（36 道题，含上琴题）、**曲目分析**（55 首歌，和模块并行，每首有看点和上琴任务）
- **指板与五度圈**：任选根音和音阶或和弦铺满指板，可切换音名和级数，支持 **CAGED / 五声 5 把位聚焦**、**音阶 × 目标和弦双层同屏叠显（Playing the Changes）**、**实战把位指型库（密排三和弦 / 壳和弦 / Drop 2 四部七和弦）**、**持续音（Drone）伴奏**、**交互式五度圈与顺阶/借用/副属和弦试听**，点击发声（清音或过载）；带计时的找音练习（支持屏幕点击或 **🎙️ 麦克风真琴弹奏识别**）
- **练耳与节奏**：内置浏览器版**音程听辨**（支持参考曲提示）、**和弦性质听辨**（三和弦与七和弦）、**功能级数听辨**（I–IV–V–I 定调，浏览器版 Functional Ear Trainer）、**14 种经典和弦进行盲听**、**8 套可调速伴奏循环发生器（Backing Track & Vamp Looper）**、**🎙️ 真琴麦克风调音与推弦音准仪（含 1/4 蓝调微推弦、半音/全音推弦靶场）**以及**随身节拍器与细分阶梯**
- **复盘日志**、**讲义**（G1～G15 全套 15 份可离线交互 HTML 讲义）、**作品与里程碑**、**资源库**、**设置**

## 配套命令（在 E:\learn 用 Claude Code 打开时可用）

- `/teach G3 音程 [主资料]`：生成单文件 HTML 讲义（带可发声的指板和上琴练习），存到 `lessons/` 并出现在「讲义」页
- `/quiz 主题`：追问式反问，包含当场上琴的任务；`/quiz 三层 主题`：每日三层递进

主题里带 G1～G15 模块号或明显是吉他乐理的内容时，两个命令会自动使用这个网站；其他主题仍然走 `agent-roadmap`。

## 改内容

所有内容都在 `assets/data-*.js` 里，纯数据，直接改：

- `data-modules.js`：阶段、模块、天数、能力自评项、每日节奏
- `data-questions.js`：自测题与答题要点
- `data-songs.js`：曲目分析、每日短练、分析步骤、练习原则
- `data-resources.js`：资料链接
- `data-method.js`：方法论文案与提示词模板
- `data-week.js`：每一天的学习内容（「本周」页），已完整覆盖 **G1～G15 全部 65 个练习日**。改完跑一次 `node build/check_week.js`，检查引用的摘录、曲目、练习编号和讲义锚点是否都存在
- `data-reading.js`：嵌在 **G1～G15** 每日页面里的 OMT 原文章节与本地谱例图（**自动生成，不要手改**，见下一节）；`data-reading-ext.js`：电吉他指板与名师实战双语补充卡片（由 `build/gen_reading_ext.py` 生成）
- `music.js`：音阶与和弦定义、音名拼写、拨弦合成

曲目里的和弦与调性以常见记谱为准，不同版本、不同调弦会有出入，最后以原录音为准。

预览某一天：在地址后加 `?today=2026-11-20`。

## 嵌在页面里的原文

「本周」与「今日」每日页面里的精读原文已全面覆盖 **G1～G15**，摘自 [Open Music Theory, Version 2](https://viva.pressbooks.pub/openmusictheory/)（CC BY-SA 4.0，共 101 节原文与 63 张本地谱例图，另在 G3～G15 配套 11 张电吉他指板与名师实战双语卡片）。英文只做了排版清理，内容没改；中文是本站翻译，同样以 CC BY-SA 4.0 提供，有出入以英文为准。每一节都标了原作者和原文链接，谱例图片的版权说明在每节末尾。

重新生成（需要 [uv](https://docs.astral.sh/uv/)；原始页面放在 `.raw/omt/`，文件名是章节 slug 加 `.html`）：

```bash
uv run --no-project --python 3.12 --with beautifulsoup4 python -I build/build_reading.py build .raw/omt
python build/gen_reading_ext.py
```

要加新的摘录：在 `build/build_reading.py` 的 `EXCERPTS` 里登记“键 → (章节, 小节编号)”，先用 `dump` 模式列出待译句段（写到 `build/omt_units.txt`），把译文按同样的编号写进 `build/omt_zh.txt`（或 G3～G15 的 `build/omt_zh_g3_g15.txt`），再用 `build` 模式生成。缺译文时脚本会报错，不会生成半成品。
